# critterfy

just a calm grey themed custom spicetify theme. i added a js file to fetch lyrics and play them in a cool animation next to the play bar :D

## Install

**Marketplace:** search "critterfy" in the Themes tab.

**Manual:**

```sh
git clone https://github.com/gaknippel/critterfy "$(spicetify path userdata)/Themes/critterfy"
spicetify config current_theme critterfy color_scheme base inject_theme_js 1
spicetify apply
```
